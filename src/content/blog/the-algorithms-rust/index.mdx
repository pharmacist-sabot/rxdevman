## เจาะลึกโค้ดจริง 5 ตัวอย่างที่แสดงจุดเด่นของ Rust

### 1. Binary Search ที่รองรับทั้งเรียงจากน้อยไปมากและมากไปน้อย `src/searching/binary_search.rs`

ความพิเศษของไฟล์นี้คือ ไม่ได้จำกัดว่าอาร์เรย์ต้องเรียงจากน้อยไปมากเท่านั้น แต่ตัวฟังก์ชันสามารถตรวจสอบทิศทางของข้อมูลผ่าน `is_asc_arr` แล้วใช้ Pattern Matching จัดการเงื่อนไขได้อย่างเป็นระเบียบ

```rust
pub fn binary_search<T: Ord>(item: &T, arr: &[T]) -> Option<usize> {
    let is_asc = is_asc_arr(arr);

    let mut left = 0;
    let mut right = arr.len();

    while left < right {
        if match_compare(item, arr, &mut left, &mut right, is_asc) {
            return Some(left);
        }
    }

    None
}
```

จุดที่น่าเรียนรู้คือการใช้ generic constraint `T: Ord` ทำให้ฟังก์ชันนี้ใช้ค้นหาข้อมูลชนิดใดก็ได้ที่เปรียบเทียบค่าได้ (ไม่ว่าจะเป็นตัวเลขหรือสตริง) และคืนค่าเป็น `Option<usize>` แทนการคืนค่า Magic Number อย่าง `-1` ตามแนวคิด Type Safety ของ Rust

### 2. Quick Sort แบบ in-place `src/sorting/quick_sort.rs`

Quick Sort มักเป็นอัลกอริทึมที่เขียนแล้วเกิดบั๊กได้ง่ายเรื่อง index bounds แต่โค้ดชุดนี้เลือกใช้เมธอด `arr.swap(i, j)` ของ Rust ซึ่งช่วยสลับตำแหน่งในหน่วยความจำโดยตรงได้อย่างปลอดภัย

```rust
fn _quick_sort<T: Ord>(arr: &mut [T], mut lo: usize, mut hi: usize) {
    while lo < hi {
        let pivot = partition(arr, lo, hi);

        if pivot - lo < hi - pivot {
            if pivot > 0 {
                _quick_sort(arr, lo, pivot - 1);
            }
            lo = pivot + 1;
        } else {
            _quick_sort(arr, pivot + 1, hi);
            hi = pivot - 1;
        }
    }
}
```

สังเกตเทคนิคการเขียน โค้ดจะเลือกทำ recursion ฝั่งที่มีขนาดสั้นกว่าก่อนเสมอ (smaller side first) แล้วเปลี่ยนอีกฝั่งเป็น loop (Tail Call Elimination) เพื่อจำกัดความลึกของ Call Stack ไม่ให้เกิด Stack Overflow รายละเอียดระดับนี้ไม่ค่อยพบในตำราทั่วไป แต่เห็นได้ชัดในโค้ดชุดนี้

### 3. Sieve of Eratosthenes แบบ Clean Code `src/math/sieve_of_eratosthenes.rs`

อัลกอริทึมหาจำนวนเฉพาะสุดคลาสสิก โดยไฟล์นี้เลือก optimize ลูปให้หยุดตรวจสอบที่รากที่สองของตัวเลขเป้าหมาย (`(num as f64).sqrt()`) และแบ่งขั้นตอนการกรองข้อมูลออกจากกันอย่างชัดเจน

```rust
pub fn sieve_of_eratosthenes(num: usize) -> Vec<usize> {
    let mut result: Vec<usize> = Vec::new();
    if num >= 2 {
        let mut sieve: Vec<bool> = vec![true; num + 1];

        sieve[0] = false;
        sieve[1] = false;

        let end: usize = (num as f64).sqrt() as usize;

        update_sieve(&mut sieve, end, num, &mut result);
        result.extend(extract_remaining_primes(&sieve, end + 1));
    }
    result
}
```

<InfoBox title="เกร็ดน่าสนใจจากโค้ด" type="info">
  ไฟล์นี้ใช้ความสามารถของ <code>macro_rules!</code> ในการสร้างเคสทดสอบ 22 กรณีจากชุดข้อมูลเดียว ช่วยลดโค้ดซ้ำซ้อนได้อย่างมาก และทุกกรณีจะถูกเทียบกับตารางจำนวนเฉพาะจริงสูงสุดถึงค่า 997
</InfoBox>

### 4. Caesar Cipher กับการจัดการ Unicode `src/ciphers/caesar.rs`

ตัวอย่างการออกแบบ API ที่ดีด้วยการส่งคืนค่าความผิดพลาดผ่าน `Result` เพื่อบังคับให้ผู้เรียกใช้จัดการ error case เสมอ

```rust
pub fn caesar(text: &str, rotation: isize) -> Result<String, &'static str> {
    if !(0..ALPHABET_LENGTH as isize).contains(&rotation) {
        return Err(ERROR_MESSAGE);
    }

    let result = text
        .chars()
        .map(|c| {
            if c.is_ascii_alphabetic() {
                shift_char(c, rotation)
            } else {
                c
            }
        })
        .collect();

    Ok(result)
}
```

จุดสำคัญคือการใช้ `.chars()` แทนการเข้าถึงผ่าน byte index โดยตรง ทำให้โปรแกรมไม่แครชเมื่อเจอกับตัวอักษร Multi-byte อย่างภาษาไทยหรืออักษรจีน พร้อมทั้งจัดการ shift ตัวอักษรผ่านระดับไบต์ (`u8`) ได้อย่างมีประสิทธิภาพ

### 5. Tower of Hanoi สไตล์ Recursive สั้นกระชับ `src/general/hanoi.rs`

ปิดท้ายด้วยตัวอย่างที่สั้นและคมชัด แสดงรูปแบบการส่ง `&mut Vec` เข้าไปสะสมประวัติการย้ายจานผ่านขั้นตอน Recursion

```rust
pub fn hanoi(n: i32, from: i32, to: i32, via: i32, moves: &mut Vec<(i32, i32)>) {
    if n > 0 {
        hanoi(n - 1, from, via, to, moves);
        moves.push((from, to));
        hanoi(n - 1, via, to, from, moves);
    }
}
```

## สิ่งที่คุณจะได้รับจากการศึกษาโปรเจกต์นี้

<ProsCons>
  <Fragment slot="pros">
    - **เข้าใจ Rust Idioms จากตัวอย่างจริง** ซึมซับการใช้ Generics, Iterator Chaining, <code>Option</code>/<code>Result</code> และ Pattern Matching อย่างเป็นธรรมชาติ
    - **เห็นแนวทางการเขียนเทสต์ที่มีมาตรฐาน** ได้เรียนรู้เทคนิค Table-driven Tests ด้วย <code>macro_rules!</code> และ Property-based Testing ผ่าน <code>quickcheck</code>
    - **เข้าใจ Time & Space Complexity เชิงปฏิบัติ** เห็นภาพชัดเจนว่าโครงสร้างข้อมูลแบบไหนเหมาะกับโจทย์ประเภทใด
    - **แทบไม่มี External Dependencies** ส่วนใหญ่ใช้เพียง Rust Standard Library ทำให้แกะโค้ดทำความเข้าใจได้ทันทีโดยไม่ต้องเปิดคู่มือ library อื่น
    - **เรียนรู้จากพลังของ Open Source** เป็นพื้นที่ฝึกฝนของนักพัฒนาทั่วโลก ทุก Pull Request ผ่านการ Code Review อย่างละเอียด
  </Fragment>
  <Fragment slot="cons">
    - **ไม่ได้ออกแบบมาสำหรับ Production** โค้ดเน้นความเรียบง่ายเพื่อความเข้าใจ อาจไม่ได้ปรับจูน Performance ถึงขีดสุดสำหรับระบบขนาดใหญ่
    - **ระดับความยากไม่เท่ากันในแต่ละไฟล์** บางหมวด (เช่น Ciphers หรือ Machine Learning) อาจต้องใช้พื้นฐานคณิตศาสตร์เฉพาะทาง
    - **ไม่มีบทเรียนเรียงลำดับ 1-2-3** คุณต้องวางแผนเลือกศึกษาตามหมวดหมู่ที่ตนเองสนใจ

TheAlgorithms/Rust ไม่ใช่แค่คลังโค้ดทั่วไปบน GitHub แต่มันคือตำรา Computer Science ฉบับมีชีวิตที่เขียนด้วยภาษา Rust โดยมีชุดเทสต์กว่า 1,600 ตัวทำหน้าที่เป็นเฉลยท้ายบท ทุกบรรทัดถูกออกแบบมาเพื่อให้คนอ่านเข้าใจ ไม่ใช่เพื่อให้เครื่องจักรประมวลผลเพียงอย่างเดียว

ไม่ว่าคุณจะกำลังเริ่มหัดเขียน Rust หรือเตรียมตัวสัมภาษณ์งานสาย Software Engineer คลังโค้ดแห่งนี้คือแหล่งอ้างอิงชั้นเยี่ยมที่คุณไม่ควรพลาด ลองเปิด Repository แล้วเลือกอ่านไฟล์แรกของคุณวันนี้ได้เลย

**ขอให้สนุกกับการอ่านโค้ด และอย่าลืมรัน `cargo test` ก่อนนอน 🦀**
